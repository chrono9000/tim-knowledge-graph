# Raw data

Private exports may be placed here temporarily for manual import, and every actual file in this directory is ignored by Git. Put a real ChatGPT ZIP here and follow [`../../agent/CHATGPT_EXPORT_GUIDE.md`](../../agent/CHATGPT_EXPORT_GUIDE.md). Never commit, copy, or publish its contents.

Supported inputs are UTF-8 `.txt`, `.md`, `.json`, and `.zip` ChatGPT/project exports. The importer reads content without copying it into the repository and stages private proposals only. See [`../../agent/README.md`](../../agent/README.md) for exact formats and commands.
